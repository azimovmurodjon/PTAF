PTAF Framework Update — Aug 6, 2026
Several fixes and new features have been merged into the framework. Please pull the latest ZIP and replace your project files.
Bug Fixes
Close all browsers + @LastScenario fix — The "Close all browsers" step was incorrectly marking the feature as failed, which caused every subsequent scenario to throw "Shared browser was closed or lost". This is now fixed. Intentional browser closures no longer affect the next scenario's browser setup.
Headless mode fix — Setting headless: "true" in config.yml was not working reliably on Playwright 1.44+. The browser was opening in headed mode instead. Fixed by controlling headless via the --headless=old Chrome flag exclusively, and always using the regular Chrome binary (not the Headless Shell).
Per-feature Glass PDF fix — When running multiple feature files, only the first feature's PDF was generated correctly; all others were empty (0 bytes). Root cause: the cucumber-pdf-report library stores font objects in static fields that become invalid after the first PDF is closed. Fixed by running each Glass PDF generation in its own subprocess.
New Features
Full-screen capture action — New fullscreenshot / fullpagescreenshot action in ActionPerformer captures the entire scrollable page (not just the visible viewport). Usage: When we perform action fullscreenshot on page homePage locator anyLocator value test-output/full-page.png
Maximize window action — New maximize / maximizewindow action resizes the current browser window to full screen via JavaScript. Useful after switching to a popup. Usage: When we perform action maximize on page homePage locator anyLocator
Auto-maximize popup windows — When maximize_browser: true, any new browser window opened by the application (e.g. links with target="_blank") is now automatically maximized. No step definition changes needed.
Per-feature PDF — two styles, two directories — The per-feature PDF report now generates two separate PDFs per feature file:
test-output/per-feature-reports/ — PTAF direct PDF (fast, always works)
test-output/per-feature-reports-glass/ — Glass-style PDF (exact cucumber-pdf-report layout) Enable via config.yml: per_feature_pdf_enabled: true and/or per_feature_glass_pdf_enabled: true
Headless override from command line — You can now override headless mode without editing config.yml: mvn test -Dheadless=true
